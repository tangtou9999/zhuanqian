# 赚钱 APP

> 赚钱啦，赚钱啦！想要赚钱，就上赚钱 APP！

面向中国市场的居家任务与灵活协作平台。核心不是招聘信息聚合，而是由平台组织真实任务、明确报酬和验收标准，让用户按能力领取并完成任务。

## 重要说明
当前所有任务和报酬均为演示数据，不代表真实订单、真实企业或收入承诺。正式运营前必须完成企业主体审核、任务真实性审核、合同与责任边界设计、个人信息保护、劳动用工合规评估，以及由合规支付服务机构提供的资金结算方案。不得以押金、垫资刷单、拉人头、培训费等方式向用户收费。

## 产品原则
1. 用户端极简：只展示能赚钱的任务，不展示复杂招聘流程。
2. 报酬透明：领取前展示计价方式、工作量、截止时间、验收标准和修改规则。
3. 任务真实：每个任务必须有可核验的需求方和明确资金来源。
4. 过程留痕：领取、提交、修改、验收、申诉和结算均有记录。
5. 公平验收：企业不能无理由拒绝验收或无限要求修改。
6. 先验证供给：先跑通少量真实任务，再扩充分类和规模。
